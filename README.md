# Portfólio Mobile — Tiago Paz

Showcase visual dos apps mobile — formato produto, não CV.

## Rodar

```bash
npm install
npm run dev
```

## Adicionar screenshots

Coloque PNGs em `public/screenshots/<id-do-projeto>/` como `1.png`, `2.png`, etc.
Aparecem automaticamente dentro dos mockups de celular.

| Projeto | Pasta |
|---------|-------|
| Status Invest | `status-invest/` |
| Fully SOMA | `fully-soma/` |
| Fit Energia | `fit-energia/` |
| Clientes Mobile | `jr-fabrica/` |
| Expedição Inter | `banco-inter/` |
| Temp Converter | `avalam/` |

## Editar conteúdo

Copy de marketing, stats e cores por app ficam em `src/data/projects.ts`.

## Build

```bash
npm run build
npm run preview
```
