# Estratégia de Portfólio e Posicionamento

## Contexto

Hoje existem dois objetivos diferentes sendo atendidos pelo mesmo domínio e pela mesma comunicação:

1. Conseguir oportunidades como desenvolvedor contratado (CLT/PJ)
2. Conseguir clientes para desenvolvimento de apps e sistemas sob medida

Embora ambos envolvam software, os públicos possuem motivações completamente diferentes.

Misturar essas mensagens reduz a conversão dos dois lados.

---

# Recomendação

Separar completamente a comunicação em dois portfólios.

# Filosofia inspirada em Uri Levine

Não vender tecnologia.

Vender a eliminação de dores.

O cliente não compra um aplicativo.

O cliente compra:

* menos retrabalho
* menos erros
* mais velocidade
* mais lucro
* mais escala
